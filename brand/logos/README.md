# Logotypy platform

Pliki `<nazwa>.png` (przezroczyste tło) używane przez `brand/make_post_logos.py` i `brand/make_reel_logos.py`.

- Źródło obecnych plików: oficjalne znaki z pakietu [Simple Icons](https://simpleicons.org) (v16.34.0, kolory marek), wyrenderowane do PNG.
- Brakujące (dodaj oficjalne pliki PNG z przezroczystym tłem, np. z press kitu / strony partnera): `sellasist.png`, `shopgold.png`, `inpost.png`, `empik.png`, `amazon.png`, `baselinker.png`, `shoper.png`, `apilo.png`, `subiekt.png`, `comarch.png`, `fakturownia.png`.
- Dopóki pliku nie ma, generator rysuje w jego miejscu elegancką kartę z nazwą platformy (zwykły tekst, bez podrabiania logo).
- Używaj logotypów tylko do pokazania, z czym integrujemy. Nie zmieniaj ich kolorów ani proporcji.
